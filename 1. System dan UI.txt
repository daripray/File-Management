Parameter:
1. Source : lokasi folder dimanapun di drive lokal komputer
2. Extensi dengan checkbox:
    - Images ekstensinya: JPG, JPEG, PNG, GIF, BMP, TIFF, TIF, WEBP, HEIC, HEIF, RAW, CR2, NEF, ORF, SR2, ARW, DNG, PSD, ICO, SVG (default, editable)
    - Videos extensinya : MP4, MOV, AVI, MKV, FLV, WMV, M4V, WEBM, MPG, MPEG, 3GP, MTS, M2TS, TS, OGV (default, editable)
    - Documents, ext : DOC, DOCX, PDF, XLS, XLSX, PPT, PPTX, TXT, RTF, ODT, ODS, ODP, CSV, XML, HTML, HTM, JSON, MD, LOG  (default, editable)
3. Keys : (untuk memilih prefix yang akan disertakan / diabaikan dalam pencarian
	- Key Include : IMG_, VID_, MOV_, DSC, PXL, JPEG, PHOTO, SAMSUNG, ANDROID, DCIM, CAM, CAMERA, DCM, PIC, MV, IMG_E
	- Key Exclude : .IMG, .VID, .MOV, SCREENSHOT, .TRASHED, .TRASH
4. Status :
	- All
	- Ori
	- Non-Ori
5. SCAN / STOP
6. Kolom DatagridView : checkBox, no, dirPath, name, type, size, originalStatus, dateTaken, mediaCreated, dateCreated, fileStatus (Ori/Non-Ori), copyStatus
